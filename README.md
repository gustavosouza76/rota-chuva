# Rota & Chuva

MVP web para motociclistas: traça a rota e mostra a chance de chuva em cada trecho, no horário em que você vai passar por ele.

- Mapa: CARTO / OpenStreetMap (Leaflet embutido)
- Rotas: OSRM · Busca: Photon / Nominatim
- Previsão: Open-Meteo (CC BY 4.0) · Radar: RainViewer
- Anúncios: Google AdSense (configuração no topo do script em `index.html`: `ADSENSE_CLIENT` e `ADSENSE_SLOTS`)

Página única (`index.html`), publicada via GitHub Pages.
